# Expense Tracker — Requirements (spec scaffold)

This is a spec scaffold for the first demo project, the **Student Expense Tracker**.
The `requirements-analyst` agent fills this in (and/or the per-project
`projects/<slug>/requirements.md`) during Phase 1.

## Idea

Build an expense tracking application for college students: add expenses,
categorize them, and view monthly spending summaries.
